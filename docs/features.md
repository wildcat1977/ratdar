# 功能與 UI 動線

## Mobile-first 主畫面

```
┌────────────────────────────┐
│ 🔴 周邊 1km：12 筆通報   登出 │ ← 頂部懸浮 (z-500)
│ 🌙                          │ ← 左上：暗色模式切換
│ 🔍                          │ ← 左上：地標搜尋
│                            │
│       🗺  全螢幕亮色地圖    │ ← Leaflet (z-0, 預設亮色)
```

## 動線

### A. 訪客看雷達
1. 進首頁，瀏覽器自動詢問定位
2. 看到 approved 通報的熱力分佈

### B. 訪客通報
1. 點「立即回報米奇」
2. 觸發 `AuthOnboarding` 抽屜（底部彈出）
3. 顯示 3 步驟說明 + 隱私權文案 + LINE / Google 登入按鈕
4. 登入成功 → 自動回首頁並開啟回報表單

### C. 已登入使用者通報
1. 點「立即回報米奇」 → 直接開啟 `ReportForm`
2. 表單最上方提供 **類型切換**：
   - `🐀 發現鼠蹤`（預設）— 紅色主題
   - `☠️ 發現毒餌` — 紫色主題，提醒寵物飼主與野生動物保育者避開
3. 表單欄位：
   - 📸 照片上傳（`accept="image/*" capture="environment"` 直接呼叫相機）
   - 📍 位置（小地圖，可拖曳圖釘微調）
   - 📝 備註（選填）
4. 送出 → AI 依類型套用不同 prompt 審核圖片 → 顯示「📡 通報成功」動畫 → 關閉 modal
5. 主畫面雙圖層即時刷新（前端 dispatch `heat-updated`）

### D. 雙圖層雷達
- 地圖右上角提供圖層切換：
  - ☑️ `🐀 鼠蹤熱區` — 紅色熱力圖 + 紅色聚合 marker
  - ☑️ `☠️ 毒餌分佈` — 紫色 ☠ 圖示 marker（不分群、永遠顯示）
- 帶寵物散步的飼主可僅勾選「毒餌分佈」，把地圖當作「毛小孩避雷指南」

### E. 地圖亮色 / 暗色切換
- 地圖左上角 `🌙 暗色模式` / `☀️ 亮色模式` 按鈕即時切換底圖
- **預設亮色**（CartoDB Light），對一般使用者可讀性更高
- 暗色（CartoDB Dark）適合夜間使用或偏好低亮度環境
- 偏好儲存至 `localStorage`（key: `mouseradar_map_theme`），下次開啟自動套用

### F. 地標搜尋（訪客可用）
- 地圖左上角放大鏡圖示，點擊後展開搜尋框
- 透過 Nominatim OSM 搜尋台灣地標 / 路名（`countrycodes: tw`）
- 選取結果後地圖跳至對應位置（zoom 15），讓使用者查看當地通報情況
- 功能完全開放，**無需登入**

### G. 聯絡管理員
- Footer 的「聯絡管理員」連結，訪客與已登入使用者皆可使用
- 填寫姓名、Email、主旨、訊息內容送出後儲存至 `contacts` 資料表
- 已登入使用者自動預填姓名與 Email
- 後台管理員在 Filament「聯絡訊息」列表查看，可標記為已讀/已回覆
- 填寫「回覆內容」儲存後，點「發送回覆郵件」按鈕透過 Gmail API 寄出 HTML 郵件
- 寄出後狀態自動更新為「已回覆」並記錄時間
